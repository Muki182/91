# 2025 男男性服务全档案系统

豪华完整版 - 专业服务人员与预约管理系统

## 功能特性

### 🎯 核心功能
- **15位专业服务人员档案** - 详细人员信息、技能标签、服务状态
- **72项服务项目** - 基础、高级、定制、专属等各类服务
- **智能预约系统** - 在线预约、状态管理、费用计算
- **实时搜索筛选** - 按名称、标签、价格、状态搜索
- **响应式设计** - 完美适配桌面和移动设备

### 🎨 界面特色
- **现代化UI设计** - 渐变色彩、卡片式布局、平滑动画
- **专业视觉效果** - 水印背景、悬浮效果、状态指示
- **直观操作体验** - 选项卡切换、模态框交互、实时反馈

### 🚀 技术栈
- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **后端**: Node.js + Express.js
- **数据存储**: JSON文件存储
- **样式库**: Tabler Icons + Google Fonts

## API接口

### 数据接口
- `GET /api/data` - 获取所有数据
- `GET /api/staff` - 获取服务人员列表
- `GET /api/services` - 获取服务项目列表
- `GET /api/bookings` - 获取预约列表

### 搜索接口
- `GET /api/staff/search?q=关键词` - 搜索服务人员
- `GET /api/services/search?q=关键词` - 搜索服务项目

### 预约管理
- `POST /api/bookings` - 创建新预约
- `PUT /api/bookings/:id` - 更新预约状态
- `DELETE /api/bookings/:id` - 删除预约

### 统计信息
- `GET /api/stats` - 获取系统统计信息

## 使用说明

### 浏览服务人员
1. 点击"人员档案"选项卡
2. 查看15位专业服务人员的详细信息
3. 使用搜索框快速筛选
4. 点击"立即预约"开始预约流程

### 查看服务项目
1. 点击"服务项目"选项卡
2. 浏览72项不同类别的服务
3. 查看价格、时长和描述
4. 直接预约特定服务

### 预约管理
1. 点击"我的预约"查看所有预约记录
2. 按状态筛选（待确认/已确认/已取消）
3. 查看预约详情和操作
4. 取消待确认的预约

### 创建预约
1. 选择服务人员或服务项目
2. 填写预约日期、时间、时长
3. 输入联系方式和特殊要求
4. 系统自动计算费用并提交
